HTTP Status Codes
      are 3-digit numbers that tell you how a server responded to a request. Here's a quick rundown of common ones:

*1xx: Informational*
- 100 - Continue: Server received headers, keep sending the body.
- 101 - Switching Protocols: Server switching protocols (like WebSocket).

*2xx: Success*
- 200 - OK: Request succeeded.
- 201 - Created: Resource created (e.g., new user).
- 204 - No Content: Success, but no content returned.

*3xx: Redirection*
- 301 - Moved Permanently: Resource moved (update your link).
- 302 - Found: Resource temporarily at another URL.
- 304 - Not Modified: Use cached version.

*4xx: Client Error*
- 400 - Bad Request: Server can't understand the request.
- 401 -  Unauthorized: Login required.
- 403 - Forbidden: Access denied (no permission).
- 404 - Not Found: Resource doesn't exist.
- 429 - Too Many Requests: Rate limited (slow down).

*5xx: Server Error*
- 500 - Internal Server Error: Generic server fail.
- 502 - Bad Gateway: Server got an invalid response from upstream.
- 503 - Service Unavailable: Server overloaded/down for maintenance.

  *most commonly used HTTP status codes* 

1. 200 - OK (Success)
2. 404 - Not Found (Resource missing)
3. 401 - Unauthorized (Auth needed)
4. 400 - Bad Request (Invalid input)
5. 500 - Internal Server Error (Server crash)
6. 201 - Created (Resource created)
7. 403 - Forbidden (Access denied)


*Async/Await* FUNCTIONS in simple terms:

- Async: Tells a function, "You can do other stuff while this is processing."
- Await: Says, "Hold up, wait for this to finish before moving on."

*How it works:*
1. Async - lets a function run without blocking others.
2. Await - pauses that specific function until the task is done.
